---
description: PR に付いたレビュー指摘を取り込んで直す
argument-hint: "[PR 番号]"
---

PR $ARGUMENTS のレビューコメントに対応します。

1. `gh pr view $ARGUMENTS --comments` と `gh api` でレビューコメントを全部読む。
2. 指摘を「直すもの」「直さないもの」に仕分けし、**直さないものは理由を明記**する。
   指摘が間違っていると判断したら、根拠を示して反論してよい。鵜呑みにしないこと。
3. 直すものを実装し、`make check` を緑にする。
4. コミットして push する。
5. 各指摘にどう対応したかを PR にコメントで返す。
