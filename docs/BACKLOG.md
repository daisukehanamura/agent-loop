# バックログ

ループの入力になるファイル。`/next-task` は上から 1 件ずつ処理する。
完了条件はテストで検証できる粒度で書くこと（曖昧だと AI も人も判断できない）。

## 次にやる

### 1. スキル登録
- [ ] `skill` テーブルを追加（`profile_id`, `name`, `category`, `level`, `years`）
- [ ] `POST /api/profiles/{id}/skills` で登録できる
- [ ] 同一プロフィール内で同名スキルの重複は 409 を返す
- [ ] `GET /api/profiles/{id}` にスキル一覧が含まれる（N+1 を出さない）
- [ ] 画面からスキルを追加・削除できる

### 2. 職務経歴の登録
- [ ] `experience` テーブル（`company`, `role`, `started_on`, `ended_on`, `description`）
- [ ] 在職中は `ended_on` が null で表現できる
- [ ] 終了日が開始日より前なら 400 を返す
- [ ] 画面で新しい順に表示される

### 3. AI による文章整形（プロダクト内 AI ループ）
- [ ] `POST /api/profiles/{id}/experiences/{eid}/refine` で職務経歴の文章を整形する
- [ ] Claude API で「生成 → 自己評価 → 再生成」を最大 `careerdeck.ai.max-refine-loops` 回まで回す
- [ ] 自己評価は「具体性・定量性・冗長さ」を観点にする
- [ ] 原文は必ず残し、整形結果は別フィールドに保持する（上書きしない）
- [ ] API キー未設定時は機能を無効化し、500 ではなく 503 を返す
- [ ] Claude API 呼び出しはテストでスタブ化し、CI が API キーなしで通る

### 4. 技術ロゴ付きのスキル表示
- [ ] スキル名から技術ロゴ（simple-icons など）を解決して表示する
- [ ] 解決できない場合は頭文字のフォールバックを出す
- [ ] ダークモードでロゴが潰れない

### 5. GitHub リポジトリ連携ポートフォリオ
- [ ] GitHub API から自分の公開リポジトリを取得する
- [ ] 言語構成・スター数・最終更新をカードで表示する
- [ ] 表示するリポジトリを選んで並び替えできる
- [ ] レート制限に当たったらキャッシュを返す
